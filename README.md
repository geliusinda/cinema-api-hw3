# Cinema API (ДЗ №3)

API для розкладу кінотеатру та бронювання місць. Проєкт використовує NestJS, Mongoose і MongoDB.

## Запуск

Потрібні Node.js 24, npm та Docker Compose.

1. Встановіть залежності командою `npm ci`.
2. Створіть `.env` на основі `.env.example`.

   ```dotenv
   PORT=3000
   MONGODB_URI=mongodb://127.0.0.1:27017/cinema
   ```

3. Запустіть MongoDB командою `docker compose up -d --wait`.
4. Щоб додати тестові дані, виконайте `npm run seed`. Повторний запуск не створює дублікати.
5. Запустіть API командою `npm run start:dev`.

Swagger доступний на [localhost:3000/docs](http://localhost:3000/docs). Щоб перевірити API вручну, відкрийте `requests.http` у VS Code з розширенням REST Client і виконуйте запити згори вниз. Для першого проходу використайте свіжу базу. Для автоматичної перевірки запустіть `npm test` з доступною MongoDB.

## Зберігання даних

Фільми, зали й сеанси зберігаються в трьох колекціях. Документ сеансу містить місця та бронювання. Їхня кількість обмежена місткістю залу.

Один запит до MongoDB перевіряє, що всі обрані місця вільні, позначає їх зайнятими й додає бронювання. Якщо хоча б одне місце зайняте, запит повертає 409 і документ не змінюється. Скасування так само одним оновленням видаляє бронювання і звільняє його місця. Для цього достатньо звичайного екземпляра MongoDB.

API повертає ідентифікатори як рядки з 24 шістнадцяткових символів. Ціни вказуються в копійках. Фільтр `date` у `GET /showings` працює за UTC. На однаковий час початку сеанси впорядковуються за ID за зростанням.

Схема залу може містити до 10 000 місць, щоб документ сеансу залишався в межах розміру BSON.
